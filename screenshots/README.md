# SpendWise Student — Screenshots

This section showcases the main features and user interface of SpendWise Student.

## Login Page

Users can sign in to access their personal finance dashboard.

## Financial Dashboard

Displays total balance, income, expenses, category-wise analytics, and recent transactions.

## Add Transaction

Allows users to record income or expenses with a title, amount, category, and date.

## Transaction History

Displays recorded transactions with their categories, dates, and amounts.
